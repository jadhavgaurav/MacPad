# NotePad v2 Feature Plan

> Status values: Planned, In progress, Done (verified in app), Done (unit tested), Blocked.

| # | Feature | Area | Status |
|---|---|---|---|
| 1 | Recover set-aside (quarantined) tabs | Core + UI | Done (unit tested and verified in app) |
| 3 | One sheet for Close Others / Close to the Right with unsaved tabs | AppState + Dialogs | Done (verified in app) |
| 9 | Auto-detect and convert line endings and encodings | Core | Done (detection on open already existed; convert-all command added with it) |
| 2 | App-wide unsaved indicator (Dock badge) | AppDelegate | Done (code in place; Dock badge not yet seen on screen) |
| 4 | Find in preview and editor together; find bar stays open across tabs | Find + Preview | Done (preview highlights and find bar across tabs verified in app; regex and whole-word matches highlight in the editor only) |
| 5 | Two-way preview and editor scroll sync; heading jump | Preview | Done (editor to preview and heading jump verified in app; preview to editor needs a real scroll gesture and is checked by code only) |
| 6 | Multiple cursors and column selection (Option-drag) | Editor | Done (verified with real mouse and key events in a probe and in app; undo restores a single caret) |
| 7 | Line commands: duplicate, move up/down, join, sort, remove duplicates | Core + Editor | Done (18 unit tests; duplicate, join, sort and remove duplicates verified in app; move verified by unit tests only) |
| 8 | Regular-expression find and replace with capture groups | Core find | Done (unit tested) |
| 10 | Spell check via system, user dictionary | Editor | Done (system spell checking is on; the user dictionary is the system one) |
| 11 | Selection counts and reading-time estimate | Stats | Done (verified in app) |
| 12 | Snippets and templates | Core + UI | Done (unit tested and verified in app) |
| 13 | Quick Look preview for text and Markdown | Extension | Blocked (needs an Xcode app-extension target) |
| 14 | Services and Shortcuts actions | Intents | Services done (entry in place; not triggered by our test tools); Shortcuts blocked (needs Xcode) |
| 15 | Share sheet | UI | Done (File > Share; the share sheet was not opened by our test tools) |
| 16 | Focus mode (hide chrome, centred column) | UI | Done (verified in app) |
| 17 | Tabs dragged out into their own window | Windows | Planned |
| 18 | Version history of saved files (size-capped) | Core | Planned |
| 19 | Read-only and locked file state, Save As fallback | Core + UI | Done (verified in app) |
| 20 | Export Markdown to HTML and PDF | Preview | Done (unit tested; the save panel was not run in app) |

Rules for every feature: pure logic in NotePadCore with unit tests; UI verified in the running app; lint strict; release build; commit per feature.
