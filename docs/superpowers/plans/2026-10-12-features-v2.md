# NotePad v2 Feature Plan

> Status values: Planned, In progress, Done (verified in app), Done (unit tested).

| # | Feature | Area | Status |
|---|---|---|---|
| 1 | Recover set-aside (quarantined) tabs | Core + UI | In progress |
| 3 | One sheet for Close Others / Close to the Right with unsaved tabs | AppState + Dialogs | Planned |
| 9 | Auto-detect and convert line endings and encodings | Core | Done (detection on open already existed; convert-all command added with it) |
| 2 | App-wide unsaved indicator (Dock badge) | AppDelegate | Planned |
| 4 | Find in preview and editor together; find bar stays open across tabs | Find + Preview | Planned |
| 5 | Two-way preview and editor scroll sync; heading jump | Preview | Planned |
| 6 | Multiple cursors and column selection (Option-drag) | Editor | Planned |
| 7 | Line commands: duplicate, move up/down, join, sort, remove duplicates | Core + Editor | Planned |
| 8 | Regular-expression find and replace with capture groups | Core find | Planned |
| 10 | Spell check via system, user dictionary | Editor | Planned |
| 11 | Selection counts and reading-time estimate | Stats | Planned |
| 12 | Snippets and templates | Core + UI | Planned |
| 13 | Quick Look preview for text and Markdown | Extension | Planned |
| 14 | Services and Shortcuts actions | Intents | Planned |
| 15 | Share sheet | UI | Planned |
| 16 | Focus mode (hide chrome, centred column) | UI | Planned |
| 17 | Tabs dragged out into their own window | Windows | Planned |
| 18 | Version history of saved files (size-capped) | Core | Planned |
| 19 | Read-only and locked file state, Save As fallback | Core + UI | Planned |
| 20 | Export Markdown to HTML and PDF | Preview | Planned |

Rules for every feature: pure logic in NotePadCore with unit tests; UI verified in the running app; lint strict; release build; commit per feature.
